# M6 · Demo release hardening

Build notes for M6. The checklist is in [docs/PLAN.md](../PLAN.md#7-milestones).

## Acceptance suite A01 to A05 in demo mode

`npm run acceptance` runs every scenario of REQUIREMENTS.md section A as one suite (unit tests through the real API, then the Playwright journeys at 390 and 1440 px).

| ID | Scenario | Where it is checked |
|---|---|---|
| A01 | Register, pay, check in, assign a trainer, publish, log, review, renew | `src/api/m3Acceptance.test.ts`; `e2e/a01.ts` through the screens (`m4-acceptance.spec.ts`, `desktop-flows.spec.ts`) |
| A02 | Trainer transfer | `src/api/clients.test.ts`, `src/domain/permissions.test.ts`; `e2e/m2-acceptance.spec.ts` |
| A03 | Two requests for one slot | `src/api/m3Acceptance.test.ts`, `bookings.test.ts`, `deskBookings.test.ts`; `e2e/a03.ts` (two tabs and two desks) |
| A04 | Freeze, expiry, cancellation, refund, duplicate payment notice, no-show, override | `src/api/m3Acceptance.test.ts` |
| A05 | Tenant and branch isolation, consent-restricted photos, role-scoped exports | `src/api/a05Acceptance.test.ts`, `src/api/m4Acceptance.test.ts` |
| A05 | **Backup restore in a test environment** | Not possible in demo mode. Moved to M6B. |
